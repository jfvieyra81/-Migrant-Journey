MIGRATION JOURNEY · SS7 Review Game (v4 · Helios cinematics + Mission Checks)
===========================================================================

HOW TO OPEN / CÓMO ABRIR
1. Download SS7_Migration_Journey.zip and unzip it (on a Chromebook: open the ZIP in Files, then copy the
   folder "SS7_Migration_Journey" to My files / Downloads).
   Descargue el ZIP y descomprímalo (en Chromebook: abra el ZIP en Archivos y copie la carpeta a Mis archivos).
2. Open the folder and double-click index.html (opens in Chrome).
   Abra la carpeta y haga doble clic en index.html.
3. No internet, server, account, or installation needed. / No necesita internet, servidor, cuenta ni instalación.

IMPORTANT: keep index.html and the media/ folder together. Do not open index.html from inside the ZIP
preview — unzip first. If the media folder is missing, the game still works with simple animations.
IMPORTANTE: mantenga index.html junto a la carpeta media/. Descomprima antes de abrir.

FOLDER CONTENTS
  index.html                 the game (HTML/CSS/JS + embedded photos)
  media/*.mp4                10 cinematics (H.264, 1280x720, 30 fps, silent)
  media/*.webm               same clips in VP9 (backup for browsers without H.264)
  media/stills/*.jpg         3 still frames per clip (Reduced Motion mode)
  README.txt                 this file
  TEACHER_GUIDE.txt          teacher guide (Spanish)

DATA / DATOS
Progress is saved only in this browser (localStorage key "ss7_migration_journey_v1"): name, symbol,
priority, language mode, resources, items, badges, route, decisions, Mission Check results, final
answer, settings. Nothing is sent anywhere. "Start Over" (2 confirmations) erases it.

Photo credits: Wikimedia Commons (list at the end of the game report). Cinematics: original 2D
animations made with Helios (@helios-project/cli 0.45.2) for this game.
